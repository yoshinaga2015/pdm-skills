# 合格試験の約束

この文書は、ui-video-builder で動画の仕組みを生成するエージェントが読む。読み終えると、生成した仕組みが合格試験 `scripts/check.mjs` に何を渡せばよいかが分かる。

合格試験は、生成した仕組みが次を満たすかを確かめる。合格試験は生成させず、このスキルが配る決まった物として使う。中身を書き換えない。

| 確かめること | 中身 |
| --- | --- |
| 同じコマは同じ絵になる | 場面ごとに中ほどの1コマを、別々のページで3回撮り、PNGのバイト列が一致するか。まれにしか起きない揺れを見逃さないため、3回撮る。`--repeat`で回数を変えられる |
| 空のコマが無い | 縦型の動画で、0.25秒ごとに撮り、絵の範囲を64px四方の升に分け、明るさのばらつきが小さい升が6割を超えるコマが無いか。強調の印が、絵の範囲の端から24pxの内側に収まるか |
| 縦型の文字が安全域に収まる | 縦型の動画で、10コマごとに、字幕・見出し・注記・ロゴがTikTokの安全域に収まるか |
| 強調の印を十分な長さ映す | 印のある動画で、印ごとに、描き終えてから1.5秒以上、切れずに見えているか |
| 印の線が文字に重ならない | 印のある動画で、枠と丸の線が、文字・ボタン・小さなアイコンに重ならないか |
| 効果音と印の時刻が合う | 効果音のある動画で、効果音が鳴るコマの前後0.5秒に、同じ意味の印(印、カーソル、クリックの波紋)が見えるか |

## 撮る関数のファイル

生成した仕組みは、撮る関数のファイルを1つ用意する。置き場は生成した仕組みの中で決めてよい。たとえば `video/check-adapter.mjs` である。合格試験は次のように流す。

```bash
node <ui-video-builder の置き場>/scripts/check.mjs --adapter video/check-adapter.mjs
node <ui-video-builder の置き場>/scripts/check.mjs --adapter video/check-adapter.mjs --video demo-vertical --check same,safe
```

撮る関数のファイルは、次の3つの関数を書き出す。

### videos()

動画の一覧を返す。1つの動画は次の形にする。

| 項目 | 必須 | 中身 |
| --- | --- | --- |
| `id` | 必須 | 動画の名前 |
| `fps` | 必須 | 1秒のコマ数 |
| `width`、`height` | 必須 | 動画の大きさ(px) |
| `scenes` | 必須 | 場面の並び。1つの場面は `{ id, from, durationInFrames, continues? }`。`from` は動画の始めから数えたコマ。`continues` が真の場面は、前の場面の絵を切らずに続ける場面で、合格試験は前の場面の始めから続けて撮る |
| `vertical` | 任意 | 縦型か。省くと、高さが幅より大きい動画を縦型とみなす |
| `pageScale` | 任意 | 動画のpxで数えた、ページのpx1つ分の大きさ。ページを動画より小さく描き、画素の密度を上げて撮るときに使う。省くと1 |
| `picture` | 任意 | 空のコマを確かめる、絵の範囲 `{ x, y, width, height }`(動画のpx)。字幕の帯を除いた範囲にする。省くと動画の全体 |
| `blank` | 任意 | 真にすると、横型の動画でも空のコマを確かめる。省くと、縦型の動画だけで確かめる |
| `blankExemptScenes` | 任意 | 空のコマを数えない場面の`id`の一覧。地の色の上に大きな文字や絵だけを出す場面に使う |
| `marks` | 任意 | 真にすると、印の長さと線の重なりを確かめる。強調の印を描く動画で真にする |
| `cues` | 任意 | 効果音の並び `[{ frame, kind, mark }]`。kind は `"mark"`(印)か `"click"`(カーソルかクリックの波紋)。mark は印の id で、省くとどの印でもよい |
| `allowedAreas` | 任意 | 印ごとに、安全域の代わりに置いてよい範囲。たとえば `{ "data-video-card": { x, y, width, height } }` |

### shoot(opts)

決めた範囲のコマを撮る。呼ばれるたびに、**新しいページ**を開く。前の呼び出しの状態を持ち越さない。

| 引数 | 中身 |
| --- | --- |
| `video` | 動画の名前 |
| `from`、`to` | 撮る範囲のコマ。`from` のコマでページを開き、`to` の手前まで1コマずつ進める |
| `shoot(frame)` | 真を返すコマだけ撮る |
| `onShot(frame, png, page, extra)` | 撮ったコマの画像を渡す。`png` は動画の大きさのPNGのバイト列(Buffer)。`page` はそのコマを描いているPlaywrightのページ |
| `onFrame(frame, page, extra)` | 省略できる。コマを進めるたびに、撮る前に呼ぶ。合格試験はここでページの要素の矩形を測る |

`extra` は、強調の印が `page` と別のページに描かれるときに渡す。縦型で、アプリのページを台紙の窓に置くときがこれに当たる。形は `{ appPage, window, appScale }` で、`appPage` は印を描いたページ、`window` は台紙の窓の矩形(動画の px)、`appScale` は `appPage` の1pxが窓で何pxになるか。横型なら `{ appPage: page, window: 動画の全体, appScale: 1 }` を渡すか、省く。

1コマ進めるたびに、ページの時計を1/fps秒だけ進め、アプリの動きをその時刻にそろえてから、`onFrame` と `onShot` を呼ぶ。`onShot` と `onFrame` は非同期の関数のことがあるので、待ってから次のコマへ進める。

### setup()

省略できる。合格試験の始めに一度だけ呼ぶ。ビルド、配信のサーバーの起動、ブラウザの起動をここで行い、`close()` を持つ物を返す。合格試験の終わりに `close()` を呼ぶ。

## ページの印

合格試験は、ページの要素に付けた次の属性を読む。字幕や強調の印を足したら、属性を付ける。

| 属性 | 付ける要素 | 確かめること |
| --- | --- | --- |
| `data-video-caption` | 上端の字幕 | 安全域 |
| `data-video-subtitle` | 発話の字幕 | 安全域 |
| `data-video-heading` | 見出し | 安全域 |
| `data-video-legal-note` | 法務などの注記。値を `bottom` にすると、TikTokの部品に隠れてよい置き方として安全域で数えない | 安全域。字幕・見出し・ロゴと重ならないか |
| `data-video-dev-note` | 「開発中の画面です」などの断り | 安全域 |
| `data-video-logo` | ロゴ。中の文字はロゴと一緒に数える | 安全域 |
| `data-video-emphasis` | 赤い丸、枠、取り消し線、蛍光ペン、早送りの札などの強調の印 | 絵の範囲の端から24pxの内側に収まるか |
| `data-video-mark` | 強調の印の線(SVG の path か rect)。値は印の id。`data-video-mark-kind`(`circle`、`box`、`strike`、`highlight`)と、描き終えたら `"1"` になる `data-video-drawn` も付ける | 印の長さ、線の重なり、効果音との時刻 |
| `data-video-cursor` | マウスのカーソル | 効果音との時刻 |
| `data-video-tap` | クリックの波紋 | 効果音との時刻 |

見えていない要素、つまり祖先までの不透明度の積が0.05より小さい要素は数えない。

## 合格の判定

すべての動画で、確かめた3つがすべて0件なら「合格」と出し、終了コード0で終わる。1つでも見つかれば「不合格」と、何が何件かを出し、終了コード1で終わる。

合格試験が「不合格」を出したら、生成した仕組みの側を直す。合格試験の値やしきい値を変えて合格させない。

1本の合格試験は数分かかる。「同じコマ」が合わないときは、`scripts/repeat.mjs`で同じコマを何回も撮り、違う範囲を出してから原因を探す。カメラや字幕の置き場を試すときは、`--check blank`や`--check safe`だけを流すと早い。
